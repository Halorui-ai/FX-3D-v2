## 4. 技术方案

### 4.1 数据管线（Python）

- Python：`C:\Users\Ray\AppData\Local\Programs\Python\Python313\python.exe`，或旧 venv `C:\Users\Ray\.workbuddy\binaries\python\envs\default\Scripts\python.exe`（已有 pillow / matplotlib / shapely）。需要 opencv、numpy 就 pip 安装。
- 步骤：
  1. **配准**：每个区的卫星截图 ↔ Esri 正射影像，用特征匹配（SIFT + RANSAC 相似变换）或人工控制点；2D 截图 ↔ 卫星截图用标签图标位置求初值再细化。每个区输出叠合检查图，**用眼睛看是否对齐**，不对齐不许往下走。
  2. **提取轮廓**：2D 截图里楼栋是灰蓝色块，按颜色阈值分割 → 轮廓 → 多边形（保留 L 形、凹口，不要简化成矩形）。对照卫星截图修正，补充 2D 图里没有的东西。
  3. **台账**：`data/campus.geojson`，每栋含 `id`（如 `E12`）、`zone`、`type`（production / office / canteen / warehouse / utility / other）、`floors`、`height`、屋面类型（pv 光伏 / equipment 设备 / white 白色平屋面 / metal）。另有道路（中心线 + 宽度）、大门、田径场、球场、停车场、绿地、物料输送连廊。坐标用 WGS-84 经纬度，另存一份本地米制坐标。
  4. **校验**：楼栋不重叠；道路不压楼；联合办公楼夹在两栋厂房之间；栋数和栋号与 App 平面图一致。把台账画回正射影像，逐区输出对照图 `docs/check/zone_X.jpg`。

### 4.2 模型与查看器

- **Three.js 最新版 + esbuild 打包成单个普通脚本（IIFE）**，贴图以 data URI 内嵌到 js 里。这样 `file://` 双击 `index.html` 就能离线打开，又能用最新渲染特性，不牺牲效果。（`file://` 下不能用 ES module import，也不能 fetch 本地文件、不能把本地 `<img>` 当贴图，所以必须打包 + 内嵌。）
- 另附 `启动.bat` 作为备用（本地静态服务器）。
- 坐标：场景正北 = −Z，东 = +X，1 单位 = 1 米。默认视角正北朝上，带指北针。
- 建筑：按台账多边形挤出，立面按实拍做（见 4.3），屋面做光伏阵列、设备机组、女儿墙。
- 地面：道路、铺装、绿地、田径场（红跑道 + 绿草坪）、球场。地形基本是平地。
- 物料输送连廊：架空的封闭管廊，连接楼与楼、区与区，位置按卫星图。
- 光照天气：按 lat 34.55 算真实太阳位置，时间滑块（清晨 / 正午 / 黄昏 / 夜晚）；天气切换（晴 / 多云 / 阴 / 雨 / 雾）。
- 去塑料感：带污渍和接缝的粗糙材质、环境光遮蔽（GTAO）、柔和阴影、大气透视（雾）、色调映射、夜间窗户和路灯发光、雨天地面反光。
- 交互：点击楼栋显示栋号和类型；图层开关（栋号标签 / 道路 / 设施）。
